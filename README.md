# Programación Web I — SIS-0300

**Carrera:** Ingeniería de Sistemas  
**Facultad:** Ingeniería  
**Universidad:** Universidad Privada Domingo Savio — Tarija, Bolivia  
**Semestre:** Quinto

---

## Descripción

Materiales de laboratorio para la asignatura Programación Web I. El módulo enseña a construir aplicaciones web completas usando React con TypeScript y Supabase como backend, a través de un proyecto incremental que evoluciona durante todas las clases.

---

## Stack tecnológico

| Herramienta     | Uso                                     |
| --------------- | --------------------------------------- |
| React + Vite    | Framework frontend y bundler            |
| TypeScript      | Tipado estático                         |
| Supabase        | Base de datos, autenticación y API REST |
| Tailwind CSS    | Estilos utilitarios                     |
| React Router v6 | Navegación entre páginas                |
| Recharts        | Reportes y gráficos                     |

---

## Proyecto del módulo

A lo largo del módulo se construye un **sistema de gestión de inventario** de forma incremental. Cada día agrega una capa nueva sobre lo anterior — desde componentes estáticos hasta una aplicación completa con autenticación, CRUD, rutas protegidas y reportes.

## Cómo usar este repositorio

Cada carpeta contiene la guía de laboratorio del día en formato `.md`. Para acceder a una guía hacé clic en el día correspondiente en la tabla de arriba o navegá directamente a la carpeta.

No se requiere instalar nada para leer las guías — se pueden ver directamente en GitHub.
